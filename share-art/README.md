وكالة دعاية وإعلان · تصميم جرافيك · مطبوعات · فيديو

## الملفات الجاهزة للاستخدام

| المجلد | المحتوى | الاستخدام |
|---|---|---|
| `brandbook/SHARE-ART-Brand-Guidelines.pdf` | دليل الهوية الكامل (22 صفحة) | للعميل والمطابع وفريق التصميم |
| `brandbook/pages/` | صفحات الدليل صور JPG | للإرسال السريع على واتساب والعروض |
| `logo/svg/` | كل الشعارات متجهة (النصوص محوّلة لمسارات) | للطباعة والتكبير بلا حدود — الملف الأساسي |
| `logo/png/` | نفس الشعارات PNG بخلفية شفافة (2400px) | للعروض والسوشيال والوورد |
| `logo/icons/` | أيقونة التطبيق، صورة البروفايل، أيقونة الموقع | للحسابات والمواقع |

## تسمية ملفات الشعار

`{التكوين}-{النسخة اللونية}`

- **التكوينات:** `horizontal` أفقي رئيسي · `horizontal-ar` أفقي للمحتوى العربي (الرمز يمين) · `vertical` عمودي · `signature` التوقيع المتماثل · `mark` الرمز منفردًا · `wordmark-ar` / `wordmark-en` الاسم منفردًا
- **النسخ اللونية:** `color` ملوّن على فاتح · `reverse-deep` على خلفية العمق · `reverse-teal` أبيض على التركواز · `mono-ink` أحادي داكن · `mono-white` أبيض على أي خلفية

**Readex Pro** للعربي والإنجليزي — مجاني بترخيص OFL من Google Fonts.

## إعادة التوليد (للمطوّر)

```bash
cd build
python3 gen_logo.py          # يولّد ملفات الشعار SVG من الهندسة والخط
python3 build_book.py        # يبني صفحات الدليل HTML
node render.js pdf ../brandbook/SHARE-ART-Brand-Guidelines.pdf
node render.js png           # صور الصفحات للمراجعة
node export_png.js           # PNG الشعارات والأيقونات
```

الألوان في `build/palette.json`، وأي تعديل فيها ينعكس على كل الملفات بعد إعادة التوليد.

> **ملاحظة:** بيانات التواصل في البطاقات والورق الرسمي (الموقع، الإيميل، الجوال، أسماء الموظفين) أمثلة توضيحية تُستبدل بالبيانات الفعلية في `build/build_book.py` (المتغير `CONTACT`).
