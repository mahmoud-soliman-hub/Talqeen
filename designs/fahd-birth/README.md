# تصميم تهنئة بمولود — فهد بن عبدالعزيز

| الملف | الوصف |
|---|---|
| `fahd-congrats.jpg` | **النسخة الأساسية**: تهنئة من محمود سليمان لعبدالعزيز (2160×3840) |
| `fahd-announcement.jpg` | نسخة البشارة بنفس محتوى التصميم الأصلي (2160×3840) |
| `source/card.html` | ملف المصدر — نسخة البشارة بتظهر لما تفتحه بـ `#alt` |
| `v1-niche/` | التصميم الأول (قوس الجص والدبدوب) للأرشيف |

## الفكرة
أوضة مولود هادية: حيطة عاجي عليها برواز جبس مقوّس، والنص جوه القوس، وسرير الطفل تحت.

## الخط
ثمانية سيرف (Thmanyah Serif Text) بأوزانه:
- Black: مبارك / الحمد لله
- Bold: فهـــد، محمود سليمان
- Medium: أخي الغالي عبدالعزيز، بن عبدالعزيز
- Regular: الأدعية
- Light: السطور الثانوية

## إعادة التصدير
```bash
cd source
node shot.js card.html out.png 1080 1920 2          # نسخة التهنئة
node shot.js card.html out.png 1080 1920 2 '#alt'   # نسخة البشارة
```
