# تصميم تهنئة بمولود — فهد بن عبدالعزيز

| الملف | الوصف |
|---|---|
| `fahd-announcement.jpg` | نسخة البشارة بنفس محتوى التصميم الأصلي (2160×3840) |
| `fahd-congrats.jpg` | نسخة التهنئة الموجهة للأب بدعاء التهنئة المأثور (2160×3840) |
| `source/card.html` | ملف المصدر — النسخة التانية بتظهر لما تفتحه بـ `#alt` |

## إعادة التصدير
```bash
node shot.js source/card.html out.png 1080 1920 2          # نسخة البشارة
node shot.js source/card.html out.png 1080 1920 2 '#alt'   # نسخة التهنئة
```
(`shot.js` سكربت Playwright بسيط بيفتح الصفحة ويصوّرها بمعامل دقة ×2)

- الخطوط: عارف رقعة (الحمد لله / مبارك / فهد)، أميري (الأدعية)، ثمانية سيرف (التفاصيل).
- الخلفية: مولّدة بالذكاء الاصطناعي ومكبّرة ×2.
